COOKIES MJ — SITIO WEB RESPONSIVE

ESTRUCTURA
- index.html: página principal
- productos.html: catálogo por categorías
- producto.html: detalle dinámico de producto (?tipo=clasicas, red-velvet, rellenas, doble-chocolate, oreo, limon)
- nosotros.html: historia, misión, visión y valores
- pedidos.html: formulario que prepara un mensaje para WhatsApp
- contacto.html: canales de contacto y preguntas frecuentes
- 404.html: página de error personalizada
- css/styles.css: estilos y diseño responsive
- js/main.js: navegación compartida, menú móvil, detalle de producto y formulario

CÓMO USAR
1. Descomprime la carpeta.
2. Abre index.html en un navegador. Para una experiencia más cercana a producción, puedes usar la extensión Live Server de VS Code.
3. Edita los textos, precios, imágenes y enlaces según la información definitiva de Cookies MJ.

RESPONSIVE
El diseño tiene breakpoints para escritorio, tablet y móvil. El ancho de contenido móvil está optimizado para pantallas compactas similares a iPhone 14/15 Pro (393 px CSS de ancho), sin limitarse a un único modelo.

IMPORTANTE
- Las imágenes de demostración usan URLs de Unsplash y requieren conexión a internet. Reemplázalas por fotografías propias cuando estén disponibles.
- El enlace de WhatsApp usa el número 59164878509 como contacto de ejemplo basado en el número compartido para la marca. Verifica que sea el número correcto para recibir pedidos antes de publicar.
- Los precios y opciones del catálogo son editables y deben confirmarse antes de publicar.
- En hosting, configura 404.html como página de error personalizada desde el panel del proveedor.
- El formulario prepara un mensaje y lo abre en WhatsApp; no almacena pedidos en una base de datos.
